## Architectural modeling highlights

### Hopper (`nvidia/h200_sxm`, `sm_90a`)
- Full 32-lane SIMT execution with uniform registers (`UR0..UR63`), 228 KiB per-SM shared memory, warp-group matrix multiply-accumulate (`WGMMA` / `GMMA`), asynchronous TMA tensor loads/stores (`UTMALDG`, `UTMASTG`, `UTMACCTL`), and hardware `mbarrier` tracking.
- Explicit memory hierarchy: 32-lane sector coalescer → SMEM/L1 → 4:1 GPC Local Request Concentrator (LRC) → 80-bank IPOLY L2 → HBM3e.
- **39 / 39** physical H200 conformance cubins bit-identical.

### Blackwell (`nvidia/b200_sxm` `sm_100a` & `nvidia/b300_sxm` `sm_103a`)
- 148 SMs, 128 uniform registers per warp, 126.5 MiB L2 cache, and **512 × 128 per-SM Tensor Memory (`TMEM`, 256 KiB/SM)** with deterministic `UTMALDG` / `tcgen05` (`UTCHMMA`, `TMEM` alloc/load/store/dealloc) modeling and automatic **TMEM leak detection**.
- **81 / 81** Qwen3.5 `sm_100a` and **81 / 81** Qwen3.5 `sm_103a` production serving kernels decoded with 0 errors; **4 / 5** FlashInfer OSS B300 binaries validated (`UTCCP` and `UTCOMMA` queued for FP4-GEMM).
- Zero-leakage calibrations fitted on locked-clock Modal B200 (`1,965 MHz`) and B300 SXM6 (`2,032 MHz`) silicon using RMSNorm + SwiGLU only, then validated **100% held-out** on Decode GEMM (`18.3%` MAE / `0/20` inversions on B200; `18.0%` MAE on B300).

## Calibration honesty invariant

Uncalibrated internal slices or future hardware targets always emit `predicted_ps: null` and `latency_us: null` rather than guessing microsecond latency. Every calibrated flagship target (`nvidia/h200_sxm`, `nvidia/b200_sxm`, `nvidia/b300_sxm`) emits deterministic `cycles`, `predicted_ps`, and `latency_us`.
